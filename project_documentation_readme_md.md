# ✈️ Air Tracker: Flight Analytics

**Domain:** Aviation / Data Analytics  
**Tech Stack:** Python, SQL (SQLite), Streamlit, Plotly, REST API Integration (AeroDataBox API via RapidAPI)

---

## 📌 Problem Statement
The **Air Tracker: Flight Analytics** project develops an end-to-end solution for extracting, managing, visualizing, and analyzing aviation data from the AeroDataBox API. The application parses nested JSON responses, transforms them into a structured relational database (`airport`, `aircraft`, `flights`, and `airport_delays`), and provides an interactive Streamlit dashboard for aviation enthusiasts, analysts, and airport operations planners.

---

## 🎯 Business Use Cases
1. **Airport Exploration:** Navigate global airport details including ICAO/IATA codes, geographic coordinates, and timezones.
2. **Flight Trend Analysis:** Visualize distributions of departures and arrivals by operational status (`On Time`, `Delayed`, `Cancelled`), airline, and route.
3. **Operational Insights:** Analyze flight delays, median delay minutes, and cancellation patterns across major hubs.
4. **Decision Support:** Offer data-driven route leaderboards and delay statistics to assist travel planners and airport resource managers.

---

## 🗄️ Database Schema Design
The relational database (`air_tracker.db`) consists of 4 normalized tables:

1. **`airport`**: Stores metadata for airports (`airport_id`, `icao_code`, `iata_code`, `name`, `city`, `country`, `continent`, `latitude`, `longitude`, `timezone`).
2. **`aircraft`**: Tracks unique aircraft details (`aircraft_id`, `registration`, `model`, `manufacturer`, `icao_type_code`, `owner`).
3. **`flights`**: Records flight schedules and status (`flight_id`, `flight_number`, `aircraft_registration`, `origin_iata`, `destination_iata`, `scheduled_departure`, `actual_departure`, `scheduled_arrival`, `actual_arrival`, `status`, `airline_code`).
4. **`airport_delays`**: Captures statistical delay metrics (`delay_id`, `airport_iata`, `delay_date`, `total_flights`, `delayed_flights`, `delay_index`, `median_delay_min`, `canceled_flights`).

## ⚙️ Installation & Setup Instructions

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/air-tracker-flight-analytics.git
cd air-tracker-flight-analytics
```

### 2. Install Dependencies
Make sure you have Python 3.8+ installed, then run:
```bash
pip install streamlit pandas requests plotly
```

### 3. Configure API Key & Initialize Database
Open `data_pipeline.py` and replace `"your_api_key"` with your RapidAPI AeroDataBox key:
```python
API_KEY = "your_rapidapi_key_here"
```
*(Note: If you run the script without an API key, the pipeline automatically uses its built-in fallback data generator so you can test all dashboards and SQL queries immediately.)*

Run the pipeline to create and populate `air_tracker.db`:
```bash
python data_pipeline.py
```

### 4. Launch the Streamlit Dashboard
```bash
streamlit run app.py
```

## 🖥️ Streamlit Application Features
- **🏠 Homepage Dashboard:** High-level KPI metrics (Total Airports, Total Flights, Registered Aircraft, Average Median Delay), interactive Plotly pie/bar charts, and a global airport map.
- **🔍 Search & Filter Flights:** Multi-criteria search by flight number, aircraft registration, airline code, origin airport, and operational status.
- **🏢 Airport Details Viewer:** Deep-dive inspector for individual airports showing timezone, coordinates, and live tables of inbound and outbound flights.
- **⏱️ Delay & Route Leaderboards:** Identifies the busiest flight corridors and ranks airports by median delay duration and cancellation volume.
- **📊 11 Project SQL Queries:** Dedicated interactive viewer that executes all 11 mandatory project SQL queries in real time alongside their formatted SQL code.
